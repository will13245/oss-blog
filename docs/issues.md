## ISSUE-1 前台本地全文搜索 + 关键词高亮 + 无结果建议

- **状态**：✅ 已完成（feature/blog-enhancement 分支，PR-1 合并）
- **负责人**：本人
- **分支**：`feature/blog-enhancement`

### 描述

Ghost 原生搜索（sodo-search）依赖外部 CDN 且搜索结果不带关键词高亮。作为自主扩展任务
（指导书候选：本地全文索引、搜索高亮和无结果建议），在自定义主题内实现完全本地的搜索组件：

- 数据源：Ghost **Content API（公开只读 key）**，一次性拉取全部公开文章建立**浏览器内存索引**
- 索引范围：标题、自定义摘要/摘要、正文纯文本、标签名
- 交互：导航栏"搜索"按钮 → 弹层输入 → 即时过滤 → 结果跳转
- 高亮：结果标题与摘要中命中片段用 `<mark>` 高亮
- 无结果：展示建议关键词（从全部标签中推荐）+ 原生 Ghost 搜索兜底链接

### 安全约束

- 仅使用 Content API key（设计上就是公开的只读 key），**不涉及任何 Admin 密钥**
- key 通过 Ghost 主题自定义设置（`{{@custom.contentApiKey}}`）注入，存于站点数据库，
  不硬编码进主题源码，不提交到仓库

### 验收条件（AC）

1. [x] 导航栏搜索按钮可点击，Enter 键也可打开/关闭弹层（键盘可达）
2. [x] 输入"开源"能同时命中标题、摘要、正文、标签含"开源"的文章
3. [x] 结果标题与摘要中的关键词以高亮（黄色背景）显示
4. [x] 输入无结果关键词时出现建议词（标签名）与 Ghost 原生搜索入口
5. [x] 断网状态下（仅本机服务）搜索功能仍可用（资源全部本地化）
6. [x] gscan 校验 0 错误

## ISSUE-2 按标签 + 阅读时长的相关文章推荐

- **状态**：✅ 已完成（feature/blog-enhancement 分支，PR-1 合并）
- **负责人**：本人
- **分支**：`feature/blog-enhancement`

### 描述

文章详情页底部新增"相关推荐"区块（指导书候选：按阅读时长和标签生成相关推荐）：

- 使用 Ghost `{{#get}}` helper 检索与当前文章**共享标签**的其他文章，排除自身，最多 3 篇
- 每个推荐卡片展示**阅读时长**（`{{reading_time}}` helper，中文化）与首个标签
- 纯模板层实现，不修改 Ghost 核心，不新增数据库查询配置

### 验收条件（AC）

1. [x] 打开任一有标签的文章，底部出现"相关推荐"
2. [x] 推荐文章与当前文章共享至少一个标签，且不包含当前文章
3. [x] 无同标签文章时显示空状态文案
4. [x] 推荐卡片展示阅读时长（"约 N 分钟读完"）
5. [x] 点击推荐卡片可正确跳转到对应文章详情页
